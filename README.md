# my projects.

> I have a few ongoing projects that are public.

### [Mewsic.](https://github.com/xeoniii/Mewsic)

This is my proudest work yet. Mewsic is a high-performance, cross-platform desktop music player built with React and Rust (Tauri). It is designed to efficiently manage large local audio libraries while seamlessly integrating online music search and download capabilities within a modern, minimalist interface.

Mewsic is available for Windows, Linux, and macOS!
